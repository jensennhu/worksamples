# Store Service-Channel Modality & Experience Outcomes

A self-contained R/R Markdown analysis demonstrating a survey/administrative
data workflow: cleaning a panel dataset, imputing a low-response rater group
from a higher-response one, reshaping long panel data into a two-period wide
format, checking a join for unmatched keys, and looping a robust-SE
regression across many outcomes at both the unit and group-aggregated level,
with results exported to a multi-sheet Excel workbook.

**This is a synthetic demonstration.** The scenario (a retail chain's
service-channel mix and its relationship to customer/employee experience
scores), the organization, and all data are fictional — generated by
`R/generate_synthetic_data.R` with a fixed seed. Nothing here reflects any
real company, client, or dataset. It exists to show technique, not findings.

## Structure

- `R/generate_synthetic_data.R` — builds a synthetic store-level panel
  (service-channel mix, experience-index scores, demographics) plus a
  region-level survey-completion feed, standing in for a data-warehouse pull.
- `R/utils.R` — a small "checked join" helper that tags unmatched keys
  instead of letting them silently drop.
- `analysis/store-modality-analysis.Rmd` — the main analysis notebook.

## Running it

From this folder:

```r
rmarkdown::render("analysis/store-modality-analysis.Rmd")
```

Requires: `dplyr`, `tidyr`, `purrr`, `glue`, `haven`, `assertr`, `estimatr`,
`openxlsx`, `knitr`, `here`, `rmarkdown`. The notebook generates its own data
on each run (no external files needed) and writes an HTML report and an
`.xlsx` results workbook to `output/`.
