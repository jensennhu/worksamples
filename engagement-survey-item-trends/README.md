# Engagement Survey Item Trends

An R script that turns a pre-scored staff engagement survey into item-level
trend tables: percent-positive by item across five years, sparkline trend
visuals rendered to PNG per item and per category, and an Excel workbook
with native (in-cell) sparklines.

Demonstrates: building small formatted HTML tables with `formattable` and
`sparkline`, converting them to standalone images via `webshot`, nesting a
data frame by group and mapping a rendering function over each group with
`purrr`, and writing native Excel sparklines with `openxlsx2`.

**This is a synthetic demonstration.** The scenario — an annual staff
engagement survey with item-level percent-positive trends for a hospital and
two benchmark comparators — the facility names, and all data are fictional,
generated by `R/generate_synthetic_data.R` with a fixed seed. Nothing here
reflects any real employer, client, or survey instrument.

## Structure

- `R/generate_synthetic_data.R` — builds a synthetic item-by-facility table
  of percent-positive scores for 2019–2023, with category groupings and
  flags for notable year-over-year change and consistently low scores.
- `R/utils.R` — a small `isid()` helper asserting a data frame is uniquely
  identified by given columns (Stata-style), used as an inline sanity check.
- `analysis/survey-item-trends.R` — the main script.

## Running it

From this folder:

```r
source("analysis/survey-item-trends.R")
```

Requires: `dplyr`, `tidyr`, `purrr`, `janitor`, `assertr`, `haven`,
`formattable`, `sparkline`, `glue`, `webshot` (with PhantomJS installed via
`webshot::install_phantomjs()`), `openxlsx`, `openxlsx2`, `here`. The script
generates its own data on each run and writes HTML/PNG tables plus an
`.xlsx` workbook to `output/`.
