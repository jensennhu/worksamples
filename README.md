# Work Samples

A collection of self-contained code samples demonstrating techniques from my
professional work. Each folder is an independent, runnable sample.

**All data in this repository is synthetic.** Company names, project
identifiers, file paths, internal libraries, and datasets have been replaced
or fictionalized — nothing here reflects any real employer, client, or
dataset. Each sample generates its own synthetic data with a fixed seed, so
it runs standalone.

## Samples

- [`service-modality-analysis/`](service-modality-analysis/) — R/R Markdown
  workflow for panel data cleaning, imputation, long-to-wide reshaping, a
  checked join, and looped robust-SE regression at unit and group-aggregated
  levels, with multi-sheet Excel export.
